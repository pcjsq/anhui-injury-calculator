# 安徽省人身损害赔偿计算器

单文件离线工具：`index.html`，双击即可在浏览器打开使用，无需联网、无需部署。

**在线访问**：https://pcjsq.github.io/anhui-injury-calculator/

## 功能

- 输入：年龄、三期天数（误工/护理/营养）、住院天数（含 ICU 天数）、医药费、伤残等级（含一处附加伤残）、误工费口径（**19 个行业门类下拉**＋单位性质口径＋固定收入）、护理人数
- 输出八项：残疾赔偿金、误工费、护理费、营养费、住院伙食补助费、交通费（市内）、精神损害抚慰金、医疗费，每项附计算式与依据，合计金额大字展示
- 一键复制明细（可粘入谈话笔录/调解方案）、打印存 PDF
- ICU 天数自动从住院伙食补助费、交通费中扣除（安徽实务口径）
- 精神损害抚慰金默认按伤残等级阶梯估算（十级 5,000 元逐级 +5,000，上限 80,000），支持手动指定

## 计算口径（2025 年度，2026 年审理适用）

| 基数 | 金额 | 用途 |
|---|---|---|
| 城镇居民人均可支配收入 | 51,737 元/年 | 残疾/死亡赔偿金 |
| 城镇居民人均消费支出 | 30,539 元/年 | 被扶养人生活费 |
| 居民服务、修理和其他服务业（非私营） | 63,508 元/年 ≈ 173.99 元/天 | 护理费 |
| 城镇私营单位就业人员平均工资 | 62,079 元/年 ≈ 170.08 元/天 | 城镇无固定收入误工费 |
| 城镇非私营单位就业人员平均工资 | 109,374 元/年 ≈ 299.66 元/天 | 误工费（可选口径） |
| 农、林、牧、渔业（非私营） | 86,712 元/年 ≈ 237.57 元/天 | 农村误工费 |
| 在岗职工年平均工资 | 111,572 元/年 | 丧葬费 ÷2 = 55,786 元 |

- 住院伙食补助费：**100 元/天，全省统一**（财行〔2014〕97号第十五条；判决实证：(2024)皖1623民初2827号、949号）
- 营养费 30 元/天、交通费 30 元/天：判决常用口径，可切换 40/50、20 元/天
- 安徽自 2019 年 12 月 16 日起城乡统一赔偿标准；精神抚慰金依皖高法〔2006〕56号第 25 条（5,000—80,000 元区间，法院酌定）

## 数据来源

- 《安徽省 2025 年国民经济和社会发展统计公报》（2026-03-19）
- 安徽省统计局 2026-06-05 发布的 2025 年城镇单位就业人员平均工资数据
- 2024 年度口径内置为过渡选项（49,539 / 29,323 / 56,902 / 60,610 / 105,416 / 69,869 / 107,605）
